راهنمای قرارداد

قرارداد BOUND از امضای type گسترده‌تر است؛ تمام فرض‌هایی را ثبت می‌کند که پیاده‌سازی‌های مستقل باید مشترکاً رعایت کنند.

پرسش‌های حداقلی قرارداد

نام، نسخه، provider، consumerها، ورودی‌ها، خروجی‌ها، خطاها، timeout، retry، ordering، concurrency، ownership، compatibility، migration و verification را مشخص کنید.

تکامل قرارداد

تغییر قرارداد باید یک رویداد مهندسی کنترل‌شده باشد. مالک، اثر بر مرز و قرارداد، شواهد پذیرش و مسیر migration یا recovery را مشخص کنید.

عامل‌ها

BOUND یک روش صرفاً هوش مصنوعی نیست. عامل‌ها مشارکت‌کنندگانی هستند که درون مرزهای مسئولیت، قراردادها، معیارهای پذیرش و کنترل‌های اعتبارسنجی تعریف‌شده توسط انسان کار می‌کنند.

مسئله

عامل‌های موازی می‌توانند پیاده‌سازی‌های محلی معقول تولید کنند اما درباره schema، خطا، مالکیت، زمان‌بندی، retry، compatibility یا state از هم واگرا شوند.

اجرای محدود

زمینه عامل باید objective، boundary مالک، سطح تغییر مجاز، قراردادهای حاکم و شواهد پذیرش را مشخص کند.

مسئولیت انسانی

عامل می‌تواند اجرای محدود و اعتبارسنجی را سریع‌تر کند؛ مسئولیت intent، trade-off، پذیرش و تغییر معماری همچنان صریح و انسانی است.

ادغام آینده

لایه پایدار باید شامل مرزها، قراردادها، مجوزها و verification ماشین‌خوان باشد. MCP، plugin، skill یا transportهای آینده می‌توانند مستقل تکامل یابند.

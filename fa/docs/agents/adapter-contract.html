قرارداد adapter

فاز ۲ معنای مهندسی لازم برای runtime آینده را تثبیت می‌کند، در حالی که transport و انتخاب‌های پیاده‌سازی را باز می‌گذارد.

execute

prepare

Agent Context را بارگذاری و اعتبارسنجی کنید: مرز، قراردادها، سطح تغییر، محدودیت‌ها، authority و شرایط پذیرش. آماده‌سازی نباید authority را بی‌صدا گسترش دهد.

execute

عامل درون context اعلام‌شده اجرا می‌شود و runtime مسئول اعمال کنترل واقعی ابزار، فایل، شبکه، credential و approval است.

verify

Agent Result را با Verification Plan ارزیابی کنید و شواهد قابل مشاهده تولید کنید.

accept

پذیرش یک تصمیم حاکمیتی است؛ موفقیت آزمون فنی به‌تنهایی مجوز merge، release یا deployment نیست.

بی‌طرفی نسبت به transport

همین معنا می‌تواند توسط MCP، plugin، CLI، CI action، service یا سازوکار آینده حمل شود، بدون تغییر قرارداد مصنوعات BOUND.

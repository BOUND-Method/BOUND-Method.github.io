BOUND در شکل‌های واقعی سیستم.

این نمونه‌ها عمداً کوچک‌اند و نشان می‌دهند چگونه یک مسئولیت سیستم به مرز، قرارداد قابل مشاهده، سطح اجرا و شواهد اعتبارسنجی تبدیل می‌شود.

REST Service

یک سرویس REST با قرارداد صریح میان سفارش و checkout.

Event-driven

مرز مبتنی بر رویداد و قرارداد OrderConfirmed.

Shared Database

پایگاه‌داده مشترک با مالکیت و دسترسی صریح.

Executable Fixture

handoff ماشین‌خوان عامل با verification قطعی.

نمونه پایگاه‌داده مشترک

پایگاه‌داده مشترک بدون مرز ضمنی مشترک.

حوزه

داده پروفایل مشتری توسط سرویس‌های Account و Notification استفاده می‌شود.

مرز

مالک state پروفایل Customer است و Notification فقط consumer مجاز است.

قرارداد

Owned state: customer profile
Consumer: Notification Service
Access: read-only projection
Fields: customer_id, email, notification_preferences
Freshness: within sync window
Forbidden: consumer direct writes

اجرا

storage می‌تواند shared database، read replica، view یا سازوکار دیگری باشد؛ مرز با مالکیت و عملیات مجاز تعریف می‌شود، نه مکان فیزیکی داده.

اعتبارسنجی

مالکیت، read-only بودن و freshness باید به‌صورت قابل آزمون ثبت شوند.

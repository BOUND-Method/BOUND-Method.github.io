نمونه REST

یک سرویس REST محدودشده.

حوزه

Order Service مالک state سفارش است و API HTTP را برای Checkout Service ارائه می‌کند.

مرز

مالکیت state سفارش و تصمیم‌های مرتبط با transition در Order Service است.

قرارداد

POST /orders/{id}/confirm
Input: order confirmation command
Success: 200
Errors: 404 unknown order; 409 invalid transition; 422 invalid input
Timeout: 2s
Compatibility: additive response fields tolerated

اجرا

پیاده‌سازی داخلی می‌تواند تغییر کند تا زمانی که قرارداد منتشرشده حفظ شود.

اعتبارسنجی

status code، schema، timeout و compatibility را با contract و integration tests بررسی کنید.

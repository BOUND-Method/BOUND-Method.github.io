مشارکت

با مرزهای صریح و شواهد مشارکت کنید.

واحد پیشنهادی مشارکت یک تغییر محدود با هدف روشن، سطح اثر، شواهد پذیرش و مسیر verification است.

پیش از تغییر repository

title معنادار، لینک‌های محلی سالم، واژگان سازگار و تمایز میان رفتار فعلی، artifact پیشنهادی، فرضیه پژوهشی و roadmap آینده را بررسی کنید.

جریان مشارکت

boundary را مشخص کنید، تغییرات مجاز را محدود کنید، قراردادهای متاثر را ثبت کنید و شواهد verification را همراه تغییر ارائه دهید.

مشارکت با کمک عامل

عامل می‌تواند implementation محدود را انجام دهد؛ توانایی ویرایش فایل یا فراخوانی ابزار به‌خودی‌خود authority تغییر boundary یا acceptance criteria نیست.

اعتبارسنجی

CI فایل‌های لازم، JSON، titleهای HTML و لینک‌های محلی را بررسی می‌کند.

آنچه این صفحه تعیین نمی‌کند

این راهنما جایگزین contributor agreement، code of conduct، security policy یا governance رسمی آینده نیست.

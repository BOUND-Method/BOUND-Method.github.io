پروژه

وب‌سایت را با اصول BOUND بسازید.

وب‌سایت باید به‌تدریج خود به نمونه‌ای از روشی تبدیل شود که مستند می‌کند: حوزه‌های روشن، مرزهای صریح، قراردادهای پایدار، اجرای مستقل و اعتبارسنجی پیوسته.

سطوح پروژه

  • وب‌سایت عمومی و landing page
  • لایه مستندات مهندسی
  • مصنوعات ماشین‌خوان
  • CI و کنترل‌های verification
  • مسیر آینده agent/plugin

پیاده‌سازی فعلی

repository یک سایت استاتیک GitHub Pages با لایه مستندات مهندسی است. CI فایل‌های لازم، schemaهای JSON، titleهای HTML و لینک‌های محلی را بررسی می‌کند.

جهت reference implementation

ساختار سایت باید خود دارای ownership، boundary، contract و verification قابل مشاهده باشد.

Roadmap، schemaهای پیشنهادی و integration آینده عامل/plugin تا زمانی که implementation و verification مستقل نداشته باشند، capability فعلی محسوب نمی‌شوند.

مرجع

واژگان و قواعد مهندسی BOUND.

این بخش قرار است مرجع فنی دقیق روش و مصنوعات ماشین‌خوان آن باشد.

اصطلاحات اصلی

  • Domain: زمینه و capability مورد نظر.
  • Boundary: مالکیت مسئولیت و حقوق تصمیم.
  • Contract: رفتار قابل اتکا میان مرزها.
  • Execution: پیاده‌سازی مستقل در محدوده.
  • Verification: شواهد قابل بررسی برای انطباق.

مصنوعات اجرای عامل

فاز ۲ مصنوعات transport-neutral برای handoff، verification planning و result reporting اضافه می‌کند.

Required Interfaces Statement

هر interface میان‌مرزی و contract/version آن را مشخص کنید و اعلام کنید وابستگی دیگری بدون افزودن صریح فرض نشده است.

وضعیت normative

مفاهیم تثبیت‌شده از tooling آینده تفکیک می‌شوند؛ schemaها فقط پس از formal specification و implementation وضعیت normative پیدا می‌کنند.

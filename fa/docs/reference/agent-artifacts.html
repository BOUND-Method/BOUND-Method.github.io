Agent Context

mission، boundary مالک، تغییرات مجاز و ممنوع، قراردادها، constraints، assumptions، acceptance، verification و authority را بسته‌بندی می‌کند؛ خود artifact به‌تنهایی authority اعطا نمی‌کند.

Verification Plan

شواهد مورد انتظار را پیش از اجرا مشخص می‌کند: schema، contract، unit، integration، static analysis، policy یا human review.

Agent Result

status، فایل‌های تغییرکرده، اثر بر boundary و contract، assumptions و evidence را گزارش می‌کند. نتیجه evidence برای acceptance است، نه مجوز خودکار merge یا deploy.

مرز protocol

این مصنوعات transport-neutral هستند و می‌توانند توسط plugin، MCP server، CLI یا runtime آینده مصرف شوند.

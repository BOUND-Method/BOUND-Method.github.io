# BOUND Website — Agentic AI Problem-First Marketing Pass

## Objective

Add a problem-first marketing layer at the top of the English and Persian homepages explaining why BOUND is compatible with agentic coding systems and how it reduces cross-agent drift.

## Added narrative

The new top section intentionally starts with the failure mode rather than with BOUND itself:

1. Context drift
2. Agent-to-agent divergence
3. Local success with system-level incompatibility
4. Silent contract mutation

The section then introduces BOUND as a control surface for reliable autonomy rather than as a restriction on agentic development.

## BOUND mechanisms presented

- **Boundary** — defines what the agent owns.
- **Contract** — freezes what neighbouring modules may rely on.
- **Team Brief** — provides a bounded execution context.
- **Verification** — detects drift before integration.

## Agent examples

The English page names Claude Code and Codex only as examples of coding agents. The copy remains provider-neutral and applies to other coding-agent systems.

## Persian edition

A native Persian version was added rather than a literal sentence-by-sentence translation. Existing embedded **Titr** headings and **Koodak** body typography are used. Mixed English technical terms are explicitly direction-isolated where useful.

## Visual / theme integration

- Dark and light theme variants included.
- RTL alignment included.
- 4-column desktop problem grid → 2-column tablet → 1-column mobile.
- No JavaScript dependency added.
- Existing methodology content, DOI metadata, schema, routing and hero interaction were not altered.

Project operations

  • Added governance, contribution, roadmap, and changelog surfaces.

Status notes

Proposed schemas and benchmark dimensions remain explicitly proposed where they have not been promoted to a formal specification or backed by reported experimental results. The documentation does not claim an implemented BOUND runtime, agent protocol, plugin, or adoption result unless a corresponding implementation or evidence is documented.

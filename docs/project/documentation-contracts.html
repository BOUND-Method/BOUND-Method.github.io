Documentation contracts.

The website now declares machine-checkable rules for how documentation pages are classified and what structural evidence they must provide.

Contract model

The contract manifest assigns each documentation surface a document type and claim policy. CI resolves every HTML page to exactly one contract and verifies the declared requirements against the page.

Current contract dimensions

  • Document type: method, guide, reference, example, agent guidance, research, project, or site index.
  • Claim policy: identifies the evidence boundary for the page, such as proposed reference material, illustrative examples, conceptual agent guidance, or research without unsupported results.
  • Required metadata: every page must expose a title and description.
  • Structural markers: selected domains can require observable terms; the method page must expose the complete BOUND lifecycle vocabulary.

Machine-readable definitions

  • Documentation contract manifest
  • Documentation contract JSON Schema
Scope: these contracts verify documentation structure and declared evidence policy. They do not claim to prove the truth of every prose statement.

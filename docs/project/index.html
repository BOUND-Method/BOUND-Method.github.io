Build the website using BOUND principles.

The website should eventually become an instance of the methodology it documents: explicit domains, boundaries, durable contracts, independent execution, and continuous verification.

Current rebuild sequence

  1. Information architecture and documentation foundation
  2. Method and Quickstart
  3. Canonical artifacts and reference
  4. Practical examples
  5. Agent integration architecture
  6. Security and sandboxing
  7. Research and benchmarks
  8. Community and governance

Website verification

The repository should progressively validate itself through broken-link checks, schema validation, example validation, documentation build checks, metadata checks, and CI deployment checks.

Implementation note

The current repository is a static GitHub Pages site. This first rebuild phase therefore adds a static documentation layer without forcing an unnecessary framework migration.

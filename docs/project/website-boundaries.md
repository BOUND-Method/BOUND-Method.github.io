# Website BOUND Map

The website's own structure is represented here as a proposed machine-readable BOUND instance.

- **Domain:** a documentation area with a defined responsibility.
- **Boundary:** what that area owns and what it must not silently redefine.
- **Interface:** an explicit relationship to another documentation domain.
- **Verification:** repository checks that provide acceptance evidence.

This map is intentionally proposed rather than normative. It describes the current documentation architecture and provides a foundation for later automated consistency checks.
